# DIKIGOROS AI plugin for Claude

The remote DIKIGOROS AI connector and the local `dikigoros-upload` helper. See the [repository README](../../README.md) for installation, configuration and what leaves this computer.

Install:

```
/plugin install dikigoros --marketplace dikigoros-ai/claude-plugins
```

Then ask Claude to set a project folder up as a DIKIGOROS matter, or run `/dikigoros:init-matter`.
